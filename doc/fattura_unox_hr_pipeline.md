# Bozza Fattura — UNOX HR Pipeline AI

**Oggetto:** Sviluppo e manutenzione annuale — Pipeline AI per automazione HR LATAM (Mexico / Colombia)

---

Progettazione, sviluppo e gestione continuativa di un sistema di automazione HR basato su intelligenza artificiale, comprensivo di: pipeline n8n multi-step per l'elaborazione automatica di documenti e dati di vendita; generazione automatica di strutture di cartelle gerarchiche su Google Drive per ogni collaboratore onboardato; estrazione strutturata di dati da immagini e PDF tramite Claude Vision API; produzione automatica di report PDF con layout personalizzato per paese (Gotenberg); riconoscimento e classificazione documenti in ingresso (obiettivi firmati, screenshot Qlik) senza intervento manuale; calcolo dinamico di bonus e risultati commerciali per cuatrimestre; integrazione con Google Docs API per la compilazione automatica di template contrattuali. Il sistema elimina completamente l'intervento manuale nel ciclo onboarding–obiettivi–risultati, garantendo scalabilità multi-paese, audit trail documentale completo su cloud e un risparmio stimato di **oltre 40 ore operative annue** per il team di gestione.
